# Color Palette Generator (Android)

A minimalist Android app that generates a random 5-color palette (HSL-based), displays it as vertically stacked tiles, and lets you copy each color code. Uses the Ocean Professional theme and Material components.

## Build

```bash
./gradlew build
```

## Run on device/emulator

```bash
./gradlew :app:installDebug
```

Then open "Palette Generator" on your device.

## Features
- Five vertically stacked, rounded tiles
- Copy HEX code per tile
- Floating Action Button to regenerate palette
- Minimalist Ocean Professional theme
